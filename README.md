# 🚀 에듀퀘스트 (EduQuest)

초등 2~3학년 수학·국어 학습 게임 허브. 갤럭시탭 크롬 PWA — 오프라인 전체 동작, 서버·계정·광고 없음.

- 기준 문서: [SPEC.md](./SPEC.md) · 구현 계획: [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)

## 게임 구성

| 월드 | 게임 | 내용 |
|---|---|---|
| 🧮 수학 | M-1 구구단 러너 | 횡스크롤 런 + 4지선다/키패드, 약점 3배 재출제 |
| | M-2 시계 폭탄 해제 | 아날로그 시계 분침 드래그(기어비 연동), 시간 계산 |
| | M-3 블록 연산 | 받아올림/내림을 블록 합체·분해 애니메이션으로 |
| | M-4 길이 다리 건설 | 판자 조합 단위 학습 (cm/m/mm → 들이/무게) |
| ✍️ 국어 | K-1 받아쓰기 스튜디오 ★ | 급수표 기반 TTS 낭독 + 자기채점 + 오답노트 |
| | K-2 띄어쓰기 슬래시 | 흐르는 문장 세로 베기, 급수표 문장 재활용 |
| | K-3 겹받침 징검다리 | 2지선다 맞춤법 돌 건너기, 콤보 배수 코인 |

공통: 코인/상점 스킨/일일 스트릭(7일 보상), 부모 모드(3초 길게 누르기).

## 실행

```bash
npm ci
npm run dev        # 개발 서버
npm test           # Vitest 단위 테스트 (182개)
npm run e2e        # Playwright 스모크 (10개 — 빌드+프리뷰 자동)
npm run build      # dist/ 산출 (서비스워커 프리캐시 자동 생성)
```

## 갤럭시탭 설치

1. `main` 브랜치에 머지하면 GitHub Actions가 GitHub Pages로 자동 배포 (저장소 Settings → Pages → Source를 "GitHub Actions"로 설정).
2. 갤럭시탭 크롬에서 배포 URL 접속 → 메뉴 → **홈 화면에 추가**.
3. 최초 1회 로드 후 비행기모드에서도 전체 동작 (TTS는 기기 내장 엔진 사용).

## 받아쓰기 급수표 등록 (부모)

부모 모드(월드맵 ⚙️ 3초 길게 누르기) → 급수표 관리:
- **Claude 활용**: "변환 요청문 복사" → Claude 챗에 급수표 사진과 함께 붙여넣기 → 받은 JSON을 "새 급수표 등록"에 붙여넣기 → 검증 → 저장.
- **직접 입력**: 한 줄에 한 문장, 빈 줄 또는 `1급` 헤더로 급수 구분. `1.` `2)` `①` 번호는 자동 제거.

## 실기기(갤럭시탭) 확인 체크리스트 — 보류 항목

자동화 테스트는 전부 그린이지만 아래는 실기기에서 확인이 필요합니다.

- [ ] 각 게임 60fps (크롬 DevTools FPS 미터, 파티클 다발 상황)
- [ ] TTS 목소리 목록/속도/반복이 삼성·구글 엔진에서 자연스러운지 (부모 모드 → 미리 듣기)
- [ ] 터치 타겟 크기 체감 (버튼 최소 48px)
- [ ] 시계 분침 드래그 감도
- [ ] K-2 세로 스와이프 인식 감도
- [ ] 홈 화면 추가 → 전체화면(standalone) 실행 → 비행기모드 전체 플로우
- [ ] Lighthouse PWA 점검

## 기술 메모

- Phaser 4.2 (스펙의 3.80+ API와 호환 확인 완료 — 전 게임 브라우저 검증), Vite, Vanilla JS 허브(DOM) + 단일 Phaser 인스턴스.
- 효과음 12종·BGM 2곡 모두 WebAudio 신디사이저 생성 — 오디오 파일 0개, 외부 CDN 없음.
- 저장: localStorage(진행도·설정, 스키마 봉투+오염 폴백) + IndexedDB(급수표·오답노트·약점 가중치·통계).
- v2 예약: Anthropic API 비전 OCR 급수표 인식 (`src/hub/parent.js`의 섹션 훅에 연결 예정).
